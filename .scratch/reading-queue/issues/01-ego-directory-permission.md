# Ego 图片目录重复授权：待确认实际效果

Status: needs-info

用户反馈在 Ego 中保存图片似乎每次都需要重新授权目录。

## 已处理

- 原实现每次收图都会通过查询参数重新加载收藏页；已改为 hash 页内切换，保留当前页面和目录会话。
- 画廊支持在同一页面连续接收收图请求，不再只启动首次下载。
- 独立扩展测试已验证页面不重载、连续两次收图成功并复用目录句柄。

## 尚未确认

测试使用 OPFS 目录，未验证 Ego 中用户选择的外部目录权限。不能据此断言实际授权弹窗已消失。

如果用户再次遇到，先区分是同一页面连续收图、关闭收藏页后收图，还是浏览器重启后收图，再定位；不要直接缓存一个“已授权”标记绕过浏览器权限。
