# 持续增长的本地收藏与恢复

Status: Accepted

收藏长期积累，不靠清理旧内容维持性能。摸排已复现整库快照互相覆盖，实测瓶颈在整库读写与全量渲染；[性能证据及适用边界](../agents/storage-and-recovery.md#性能证据)单独保留，避免把样本测量当作容量或速度承诺。

继续使用 `chrome.storage.local`，将收藏改为逐条存储，以浏览器原生 Web Locks 协调扩展页面和后台。旧数组先成功写入新记录，再移除；小编辑只读写对应记录，界面消费逐条变更事件。内容墙按批次显示，搜索与键盘导航仍覆盖完整结果。现阶段无需引入数据库依赖、全文搜索引擎或另一套图片缓存。

用户愿意首次授权目录，但不希望日常手动维护备份。因此补上本地自动 JSON 备份，修改后合并执行、浏览器启动时补写；按星期轮换最多七份，避免无限堆积。JSON 包含收藏、设置、图片来源索引及目录标识，不复制图片文件或序列化目录授权。恢复后重新选择原图片目录即可关联现有文件；旧 JSON 仍可导入，缺少的图片索引不覆盖当前索引。

这补充 ADR-0001 中首版暂缓自动备份的范围。只有授权且成功写出的副本才可用于恢复；权限失效或写入失败会显示“备份暂停”。同盘备份不承担磁盘损坏、电脑丢失或跨设备同步的保障。
