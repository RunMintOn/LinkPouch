# 长期内容收藏与目录存图

Status: Accepted

原阅读队列规格以消费后清空为目标，并排除正文存储。用户明确希望长期保留内容，减少采集操作，并能通过正文找回资料。因此，阅读队列改为收藏的一种视图，而非整个产品的目的。

## 决策与原因

- **长期保留**：默认展示全部收藏，保留原有阅读状态和备注；不引入需要持续维护的分类体系。
- **优先复用**：以 Web Clipper 的 Defuddle 抽取方式为参照，关闭评论。先使用引擎现成行为，只有真实需求不满足时才适配，不提前自建单帖、串文、引用帖抽取策略。
- **选段独立**：有文字选区时只保存选区；同一来源的不同选段与整页分别保留。外部工具生成的文字译文可直接作为选段保存，无须绑定原图或内置翻译。
- **先保存再展示**：Popup 用于展示实际保存结果和编辑可选备注，而不是增加一道保存前确认。保留快速捕获的键盘流程。
- **正文与收图分离**：两者动机不同。保存正文不自动下载图片；远程图片引用不代表图片文件已永久保存。主动收图保留帖子来源，但不新增未读任务。
- **接受目录授权，图片只存一份**：用户愿意授权目录，不接受为省掉授权而在插件与文件夹各存一份图片。画廊从授权目录读取，插件只持有目录句柄及图片来源等元数据。
- **图片附近操作**：X 收图入口放在整组图片右上角，悬停或键盘聚焦时显示。页面右下角悬浮按钮会遮挡 X 自身控件，且离帖子过远。
- **首版重功能**：画廊包含在首版范围内，先做到可用；自动备份、内置翻译、Embedding/语义检索和视觉精修暂不展开。

## 影响

目录权限失效后需要用户重新授权。正文及来源元数据仍依赖浏览器本地存储，图片目录本身不是完整备份；原有手动 JSON 导出不含图片文件。当前不承诺浏览器数据丢失后的完整恢复能力。

本决策取代旧规格对长期保留、正文存储、内容查看和站点内采集入口的限制。术语见根目录 `CONTEXT.md`；实现用法见 `README.md`；验证方法与边界见 `../agents/content-capture.md`。
